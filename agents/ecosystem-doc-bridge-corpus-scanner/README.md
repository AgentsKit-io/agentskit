# Doc-bridge Corpus Scanner

> **v1 validated** — source copied from AgentsKit Registry.

Scans an explicit documentation listing into typed paths, document types, and
staleness signals. The Registry source is source-owned in this repository;
Doc Bridge runs it only over the current redacted snapshot and report.

The local Doc Bridge runner uses a deterministic adapter for replay and safety
verification. Provider-backed execution is not enabled by this validation.
