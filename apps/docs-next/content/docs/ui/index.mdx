One controller contract, seven host bindings. Every framework package
adapts the shared state and action surface from `@agentskit/core`; hooks,
stores, services, component props, and styling primitives remain
framework-specific. This navigation map does not promise full component API
parity across bindings; use each package guide for its supported surface.
