## Install

```bash
npm install @agentskit/svelte svelte @agentskit/adapters
```

## Hello world

```svelte
<script lang="ts">
import { createChatStore } from '@agentskit/svelte'
import type { ChatConfig } from '@agentskit/core'

declare const adapter: ChatConfig['adapter']
const chat = createChatStore({ adapter })
</script>

{#each $chat.messages as m (m.id)}
  <p>{m.content}</p>
{/each}
<form on:submit|preventDefault={() => chat.send($chat.input)}>
  <input bind:value={$chat.input} />
</form>
```

## Surface

- `createChatStore(config): SvelteChatStore` — `Readable<ChatState>` + action methods + `destroy()`.

The shared state/action contract is portable; Svelte component props and
exports are binding-specific. This package does not promise full React
component parity.
