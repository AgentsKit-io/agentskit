## When to reach for it

- You want retrieval-augmented generation in a few lines.
- You need rerankers (BM25, Voyage, Jina, or a custom function) or hybrid vector+keyword search.
- You want document loaders for URL / GitHub / Notion / Confluence / Google Drive / PDF / S3 / GCS / Dropbox / OneDrive.

## Install

```bash
npm install @agentskit/rag
```

## Hello world

```ts
import { createRAG } from '@agentskit/rag'
import { fileVectorMemory } from '@agentskit/memory'
import { openaiEmbedder } from '@agentskit/adapters'

const rag = createRAG({
  embed: openaiEmbedder({ apiKey: process.env.OPENAI_API_KEY! }),
  store: fileVectorMemory({ path: './kb-vectors' }),
})
await rag.ingest([{ content: 'AgentsKit is a toolkit for AI agents.', source: 'intro' }])
const hits = await rag.search('what is agentskit')
```

## Surface

- `createRAG({ embed, store, chunkSize, chunkOverlap, topK, threshold })`.
- `chunkText` — standalone splitter.
- `createRerankedRetriever` · `createHybridRetriever` · `bm25Score` · `bm25Rerank`.
- Loaders: `loadUrl` · `loadGitHubFile` · `loadGitHubTree` · `loadNotionPage` · `loadConfluencePage` · `loadGoogleDriveFile` · `loadPdf` · `loadS3` · `loadGcs` · `loadDropbox` · `loadOneDrive`.

Remote loaders use a finite timeout and response-size limit by default. Configure
`timeoutMs`, `maxResponseBytes`, and `signal` when needed. `loadUrl` requires an
HTTPS origin in `allowedOrigins` and rejects redirects.
