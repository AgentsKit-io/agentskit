## Install

```bash
npm install @agentskit/solid solid-js @agentskit/adapters
```

## Hello world

```tsx
import { useChat } from '@agentskit/solid'
import type { ChatConfig } from '@agentskit/core'

declare const adapter: ChatConfig['adapter']
const chat = useChat({ adapter })
```

## Surface

- `useChat(config): ChatReturn` — Solid hook backed by `createStore` + `onCleanup`.
- SSR module boundary: import the hook from `@agentskit/solid/use-chat`; the root entry also includes browser UI components.

The shared state/action contract is portable; Solid component props and
exports are binding-specific. This package does not promise full React
component parity.
