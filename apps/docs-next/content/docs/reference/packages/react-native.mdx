## Install

```bash
npm install @agentskit/react-native react react-native @agentskit/adapters react-native-polyfill-globals
```

## Hello world

```tsx
// In Expo/Hermes, install and run the streaming polyfill before any AgentsKit import.
import 'react-native-polyfill-globals'
import { useChat } from '@agentskit/react-native'
import type { ChatConfig } from '@agentskit/core'
import { View, TextInput, FlatList, Pressable, Text } from 'react-native'

export function ChatScreen({ adapter }: { adapter: ChatConfig['adapter'] }) {
  const chat = useChat({ adapter })
  return (
    <View style={{ flex: 1 }}>
      <FlatList data={chat.messages} keyExtractor={m => m.id} renderItem={({ item }) => <Text>{item.content}</Text>} />
      <TextInput value={chat.input} onChangeText={chat.setInput} />
      <Pressable onPress={() => chat.send(chat.input)}><Text>Send</Text></Pressable>
    </View>
  )
}
```

Provider credentials must stay behind a server/edge endpoint; Expo and other mobile environment variables are public and must not contain long-lived API keys.

## Surface

- `useChat(config): ChatReturn` — shares the core state/action contract; component props use React Native primitives and do not promise full web parity.
