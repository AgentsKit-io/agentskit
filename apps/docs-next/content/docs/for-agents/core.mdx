## Purpose

Stable TypeScript contracts (Adapter, Tool, Memory, Retriever, Skill,
Runtime) + `createChatController` + primitives. Target: &lt;10 KB
gzipped, zero runtime deps.

## Install

```bash
npm install @agentskit/core
```

## Primary exports (main entry)

- `createChatController(config)` — state machine behind every UI
- `proposeToolCall(proposal)` — controller method that places a trusted,
  validated action into the same confirmation lifecycle; it never executes
  directly. The standalone helper is available from
  `@agentskit/core/tool-proposal`. Returns `{ getState, subscribe, send, stop, retry, edit,
  regenerate, setInput, clear, decide, approve, deny, updateConfig }`.
- `defineTool(config)` — typed tool factory with JSON-Schema input
  inference.
- `controller.send(string | ContentPart[])` preserves multimodal parts and text projection.
- `controller.decide(id, 'approve' | 'deny', reason?)` uses `ChatConfig.decisionStore` to validate the current conversation before claiming, prioritizing live controller state over memory and preserving unsaved later turns and using the pending snapshot only as a fallback (`ToolDecisionStore`, `ToolDecisionRecord`). The store provides insert-if-absent `putPending`, linearizable `get`, atomic pending-to-claimed `claim`, and matching-claim terminal `settle`. Scope it to an application-authorized conversation. Same-decision terminal replay returns the recorded tool outcome; unknown IDs raise `AK_ACTION_NOT_FOUND`, conflicting decisions raise `AK_ACTION_ALREADY_DECIDED`. Failed and claimed records are never automatically retried. Serialize different decisions per conversation to protect transcript writes.
- Identical decisions are idempotent even while claimed: they return the recorded outcome, or the original call while execution is in flight, without invoking the tool or model again. Streamed confirmations are registered before `onToolCall`. After restart, streamed decisions require current `ChatMemory`: arrival snapshots are immutable and may omit later calls; without a current conversation, `AK_CONFIG_INVALID` rejects an incomplete streaming snapshot before claiming. A live controller does not require memory.
- `approve`/`deny` are deprecated. With a decision store they delegate to `decide`, including atomic claims and typed errors; without a store they preserve generation-local behavior.
- `ChatConfig.authorizeToolCall` — trusted host authorization before tool proposal and again before execution. Callback failures default to deny.
- `createInMemoryMemory` / `createLocalStorageMemory` — default
  `ChatMemory` implementations.
- `createStaticRetriever` / `formatRetrievedDocuments` — RAG-less
  retrieval using token substring overlap; use `@agentskit/rag` for semantic
  production retrieval.
- `executeToolCall`, `consumeStream`, `createEventEmitter`,
  `parseToolArgs`, `safeParseArgs`, `isRecord`, `createId`, `generateId`, `buildMessage` — low-level
  helpers. `parseToolArgs` returns `{ args, valid }` so adapters can fail
  closed; `safeParseArgs` remains the compatibility value-only parser. IDs
  use `crypto.randomUUID()` and retain the caller-provided prefix.
- `isRecord(value)` accepts non-null objects other than arrays, including
  `Date`, `Map`, and class instances; use a schema validator when plain JSON
  objects are required.
- `AgentsKitError`, `AdapterError`, `ToolError`, `MemoryError`,
  `ConfigError`, `RuntimeError`, `SandboxError`, `SkillError`,
  `ErrorCodes` — error taxonomy.
- Token budget: `compileBudget`, `approximateCounter`.
- Progressive tool args: `createProgressiveArgParser`,
  `executeToolProgressively`.
- `createVirtualizedMemory` — hot-window + cold-retriever wrapper
  (also re-exported from `@agentskit/memory`).
- Untrusted-input fencing lives in the `@agentskit/core/security` entry:
  `fenceUntrustedContent(content, opts?)` + `UNTRUSTED_CONTENT_DIRECTIVE`
  wrap attacker-influenced text so the model treats it as data, not
  instructions (the mitigation companion to `createInjectionDetector`).
- Multi-modal content parts: `textPart`, `imagePart`, `audioPart`,
  `videoPart`, `filePart`, `partsToText`, `normalizeContent`,
  `filterParts`.
- Agent-loop internals (advanced): `buildToolMap`, `activateSkills`,
  `executeSafeTool`, `createToolLifecycle`.
- Memory serialization: `serializeMessages`, `deserializeMessages`; validate untrusted records with `validateMemoryRecord` from `@agentskit/core/memory-validation`.

## Minimal example

```ts
import { createChatController } from '@agentskit/core'
import { anthropic } from '@agentskit/adapters'

const controller = createChatController({
  adapter: anthropic({ apiKey: process.env.ANTHROPIC_API_KEY!, model: 'claude-sonnet-4-6' }),
})

controller.subscribe(() => console.log(controller.getState().messages))
await controller.send('Hello')
```

## Common patterns

- Wire a controller into any framework via `getState` + `subscribe`
  (see the framework bindings under [For agents](/docs/for-agents)).
- Compose tools with [`composeTool`](/docs/reference/recipes/tool-composer) or
  wrap failing ones with
  [`wrapToolWithSelfDebug`](/docs/reference/recipes/self-debug).
- Gate risky operations with
  [`createApprovalGate`](/docs/reference/recipes/hitl-approvals) + HITL + signed
  [audit log](/docs/reference/recipes/audit-log).
