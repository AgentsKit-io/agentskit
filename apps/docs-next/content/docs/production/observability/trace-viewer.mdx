---
title: Trace viewer
description: Generate a self-contained HTML trace file from any run — inspect spans offline without a tracing backend.
---

When you need to debug a specific run without shipping to LangSmith or standing up a Jaeger instance, `createFileTraceSink` records spans to a local JSON report and `flush()` writes a standalone HTML page.

```ts
import { createFileTraceSink, createTraceTracker } from '@agentskit/observability'

const sink = createFileTraceSink('.agentskit/traces')
const tracker = createTraceTracker({
  onSpanStart: sink.onSpanStart,
  onSpanEnd: sink.onSpanEnd,
})

const runtime = createRuntime({ adapter, observers: [{ name: 'trace-tracker', on: event => tracker.handle(event) }] })
await runtime.run(task)

const out = await sink.flush({ traceId: 'run-1' })
console.log(out.json, out.html)
```

Open the generated file in any browser. Zero server. Zero tracking.
