## Authoring

- `defineTool` (core) — JSON-Schema inference.
- `defineZodTool` — Zod-based with runtime validation.
- `composeTool` — chain N tools into one macro tool. [Recipe](/docs/reference/recipes/tool-composer).
- `wrapToolWithSelfDebug` — LLM-corrected retries. [Recipe](/docs/reference/recipes/self-debug).
- `createMandatorySandbox` — allow / deny / require-sandbox / validators. [Recipe](/docs/reference/recipes/mandatory-sandbox).

- `createMcpServer` — publish AgentsKit tools to any MCP host.
