---
title: Skill marketplace
description: Publish, install, version skills. Semver range resolution.
---

`createSkillRegistry` is the local primitive for publish/install/version. For a hosted, shadcn-style catalog of ready-made agents you can pull with one command, see the [Registry](https://registry.agentskit.io).

```ts
import { createSkillRegistry, customerSupport } from '@agentskit/skills'

const registry = createSkillRegistry()

await registry.publish({
  version: '1.0.0',
  publisher: 'example-org',
  skill: customerSupport,
})
const resolved = await registry.install('customer-support', '^1.0.0')
```

## API

| Method | Purpose |
|---|---|
| `publish(skill)` | add a version |
| `install(name, range)` | resolve semver range |
| `list()` | all available |
| `unpublish(name, version)` | remove |

## Ranges

`1.2.3` · `^1.2.3` · `~1.2.3` · `>=1.2.0 <2.0.0` · `*`.
