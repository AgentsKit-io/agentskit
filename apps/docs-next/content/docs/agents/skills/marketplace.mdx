title: Skill marketplace
description: Publish, install, version skills. Semver range resolution.
---

`createSkillRegistry` is the local primitive for publish/install/version. For a hosted, shadcn-style catalog of ready-made agents you can pull with one command, see the [Registry](https://registry.agentskit.io).

The built-in registry is intentionally in-memory and process-local. It does not
persist packages, authenticate publishers, or provide a security/compliance
boundary. For persistence or a hosted catalog, implement the `SkillRegistry`
contract in your application or use the hosted Registry service.

```ts
import { createSkillRegistry, customerSupport } from '@agentskit/skills'

const registry = createSkillRegistry()

await registry.publish({
  version: '1.0.0',
  publisher: 'example-org',
  skill: customerSupport,
})
const resolved = await registry.install('customer-support', '^1.0.0')
```

## API

| Method | Purpose |
|---|---|
| `publish(package)` | add a versioned skill package |
| `install(name, range)` | resolve semver range |
| `list()` | all available |
| `unpublish(name, version)` | remove |

## Ranges

`1.2.3` · `^1.2.3` · `~1.2.3` · `>=1.2.3` · `*`.

Compound npm ranges are intentionally not supported. Invalid versions throw a
`SkillError`; use the documented single-comparator forms or a full semver
implementation in a host-owned registry.
