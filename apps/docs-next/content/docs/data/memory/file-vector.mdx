---
title: fileVectorMemory
description: Pure-JS file-persisted vector store. Zero infra.
---

```ts
import { fileVectorMemory } from '@agentskit/memory'

const store = fileVectorMemory({ path: '.agentskit/vectors' })
```

## Options

| Option | Type | Default |
|---|---|---|
| `path` | `string` | required |
| `store` | `VectorStore` | Vectra-backed on-disk store |

`path` names a Vectra index directory. Install the optional `vectra` peer for
the default on-disk store, or provide a custom `VectorStore` implementation.

## Scale

Fine up to ~10k vectors. For larger corpora use
[pgvector](./pgvector), [pinecone](./pinecone), [qdrant](./qdrant),
[chroma](./chroma), [upstash-vector](./upstash-vector).
