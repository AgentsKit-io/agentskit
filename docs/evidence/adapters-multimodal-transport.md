The source revision and adapter tree are recorded in [the evidence metadata](./adapters-multimodal-transport.json). Subsequent report-only commits do not change that adapter tree.

Local implementation commits:

- `434ba87a`: attachment serializers, configurable transport, Cloudflare presets, OpenRouter alias, catalog variables, regression suite and changeset.
- `93a02265`: media validation and documented source limits.
- `e0cab7bc`: explicit case-insensitive gateway authentication overrides.
- `f78b492b`: retain required credential types for existing providers; add static API compatibility checks.

The existing OpenAI transport supplies `path`, `headers` and injected `fetch`. The new `openaiCompatible` and Cloudflare presets allow omitted Bearer authentication. Existing OpenAI and provider configuration types retain required `apiKey`; existing default `/v1` routing and text-only requests without parts remain compatible.

Shared history serializers send OpenAI `image_url`/`file`, Anthropic `image`/`document`, Gemini/Vertex `inlineData`/`fileData`, and Ollama `images`. Unsupported sources/modalities fail with `CapabilityUnsupportedError.code === 'CAPABILITY_UNSUPPORTED'` before I/O. Ollama accepts inline images, including image file parts, and rejects PDFs and remote URLs. Catalog placeholders are resolved only from explicitly supplied `env` values. No Cloudflare runtime binding is imported.

The [modality table](../adapter-modalities.md) is generated by a Vitest file snapshot from the HTTP test cases and checked against the recipe. Refreshing it uses the existing suite's `-u` option. [ADR 0041](../architecture/adrs/0041-adapter-content-serialization.md) records the implementation decision for maintainer review; it does not revise a core contract.
