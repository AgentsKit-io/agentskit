# Support matrix

> Generated by `node scripts/gen-support-matrix.mjs` — do not edit by hand.

A package is **supported** when an internal consumer (AgentsKit-io or NoxCodeSolutions; workspace apps count as `apps/*`) depends on it in its `package.json`.
Packages without a consumer are **experimental** (community-maintained): they carry the `experimental` npm keyword and never block a release.

A supported package is **eligible for 1.0** when it has a consumer in production or homolog, green CI on the default branch,
no breaking change in its last four versions, and docs. Eligible packages are promoted in one batch PR the owner approves.

CI on the default branch: **unknown**.
